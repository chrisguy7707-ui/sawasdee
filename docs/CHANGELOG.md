# 변경 기록

## 0.4.0 베타 (2026-11-17)

### 새 기능
- **녹음해서 비교 듣기**: 레슨의 따라 말하기 카드에서 '● 녹음하기'로 내 목소리를 녹음해 원어민 음성과 번갈아 들을 수 있어요. 마이크 권한이 필요하고, 녹음은 폰 밖으로 나가지 않아요.
- **음높이 곡선 겹쳐 보기**: 원어민과 내 소리의 음높이를 한 그래프에 겹쳐 보여 줘요(성공/실패 판정은 하지 않아요).
- **학습 기록 백업**: 내 정보에서 백업 코드를 복사해 두고, 새 폰에서 붙여 넣어 불러올 수 있어요.
- **육하원칙 질문** 단원 추가(언제·어디서·누가·무엇을·어떻게·왜).
- 공항과 입국, 마사지와 스파 단원 추가.

### 분량
- 35단원, 단원마다 단어 15개(525개), 문장 387개, 대화 연습, 음성 1,286개.

### 내용 바로잡기
- 태국어 전체 검토: 성조 코드·철자·문장·한글 발음 표기·뜻 26곳 수정, 바뀐 문구 음성 22개 새로 만듦.
- ชื่อ(이름) 음성 교체.
- 원어민 감수는 아직 받지 않았어요. 이상한 곳은 설문으로 알려 주세요.

### 화면·사용성
- 디자인 다듬기: 상단 로고·통계 칩, 탭 선택 표시, 학습 길 윤곽선과 점선 연결.
- 폰 화면에서 퀴즈 문제가 잘리던 문제 수정.
- 단어장에서 뜻이 잘리고 소리 버튼과 겹치던 문제 수정.
- 폰의 글자 크기 설정을 따라가요(아주 크게 하면 화면이 넘치지 않게 일부 제한).
- 안드로이드 16의 뒤로 가기 동작, 작은 화면 배치, 글자 대비, 버튼 터치 크기 개선.
- 앱 이름: 앱 정보에는 "사왓디-태국어 학습앱", 홈 화면에는 "사왓디".

### 알려진 한계
- 화면 낭독기(TalkBack/VoiceOver)는 지원하지 않아요(`docs/ACCESSIBILITY.md`).
- 아이폰 시험 배포는 아직 없어요(애플 개발자 계정 필요).
