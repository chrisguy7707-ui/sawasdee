# 접근성 현황

앱은 화면을 직접 그리는 방식(Rust + egui)이라, 일반 앱과 접근성 지원이 다르다. 현재 상태를 정직하게 적는다.

## 지원하는 것
- **글자 크기 설정 연동**: 폰의 글자 크기(안드로이드 "글자 크기", 아이폰 "텍스트 크기")를 키우면 앱 화면도 함께 커진다(최대 1.3배, 화면이 좁은 폰에서는 레이아웃이 깨지지 않는 한도까지만). 설정을 바꿔도 앱이 다시 시작되지 않는다.
- **글자 대비**: 보조 글자색은 WCAG 권장 대비(4.5:1) 이상. 라이트·다크 모드 모두.
- **터치 영역**: 버튼은 높이 48dp 이상.
- **작은 화면**: 320dp 폭까지 주요 화면 확인.
- **뒤로 가기**: 안드로이드 뒤로 가기·제스처가 단계별로 동작한다(레슨 중 종료 확인).
- 음성이 중요한 앱이라 소리를 끄는 설정과 글자 표시(한글 발음, 성조 화살표)를 함께 제공한다.

## 아직 지원하지 못하는 것
- **화면 낭독기(안드로이드 TalkBack, 아이폰 VoiceOver)**: 지원하지 못한다. 이 앱이 쓰는 화면 라이브러리(eframe/winit)의 접근성 연결 기능이 안드로이드·아이폰을 아직 지원하지 않는다(2026-11 확인). 라이브러리가 지원하면 버튼·카드에 이름을 붙이는 작업을 한다. 시각장애 사용자에게는 현재 적합하지 않다고 스토어 설명에 밝히는 것이 정직하다.
- **색 구분 의존**: 정답/오답은 색과 함께 아이콘·문구("정답이에요!", "정답:")로도 알려 주지만, 일부 표시는 색 위주다.
- **음성 인식 조작·스위치 조작**: 확인하지 않았다.

## 확인 방법
- 폰 설정에서 글자 크기를 가장 크게 올린 뒤 레슨 화면, 짝 맞추기, 단어장, 내 정보를 눈으로 확인한다.
- 화면 폭이 좁은 폰(320~360dp)에서 하단 버튼이 겹치지 않는지 확인한다.
