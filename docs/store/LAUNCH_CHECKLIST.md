# 출시 체크리스트

상태 표시: ✅ 끝 · 🔧 내가(개발) 할 일 · 👤 사용자가 해야 하는 일 · ⚠️ 확인 필요

## 0. 내용과 품질 (가장 중요)
- 👤 원어민 검수 의뢰 → 결과 반영 (`docs/REVIEW_REQUEST.md`). 검수 전에는 스토어 설명에 "원어민 감수"를 쓰지 않는다.
- 👤 실제 안드로이드·아이폰 기기에서 소리, 레슨 완주, 알파벳 퀴즈 확인.
- ⚠️ 음성: AI 음성(구글 Chirp 3 HD)이다. 스토어 설명에 AI 음성임을 밝혔다. 원어민 녹음으로 바꾸면 더 좋다.
- ✅ 마이크 발음 **채점**은 하지 않기로 함. 대신 '내 소리 녹음 → 원어민과 번갈아 듣기'(채점 없음, 기기 안에만 임시 저장)를 넣었다.
- [ ] 플레이 콘솔 데이터 보안 양식: 오디오는 기기 밖으로 나가지 않으므로 '수집 안 함' 유지. 앱 권한에 RECORD_AUDIO가 나타남
- [ ] 앱스토어 개인정보 질문: 마이크 접근은 있으나 수집·전송 없음. Info.plist의 마이크 사용 이유 문구(`NSMicrophoneUsageDescription`)가 심사에서 보인다

## 1. 공통 준비
- 👤 운영자 이름(개인/사업자)과 지원 이메일 정하기.
- 🔧→👤 개인정보 처리방침을 **웹 주소로 공개**(`docs/store/PRIVACY_POLICY.md`의 빈칸 채우고 GitHub Pages 등에 올리기). 스토어 등록에 웹 주소가 필요하다.
- 👤 앱 이름 상표·중복 확인: "사왓디"는 흔한 인사말이라 상표로는 약하고, 같은 이름의 다른 앱이 있을 수 있다. 스토어에서 검색해 본다.
- ✅ 오픈소스 라이선스 목록 `THIRD_PARTY_LICENSES.md`(강한 카피레프트 없음). 🔧 앱 안에 '오픈소스 라이선스' 화면 또는 링크 추가(글꼴 OFL 고지).
- ✅ 아이콘(금색 코끼리), 서명 키 백업, 버전 0.4.0(변경 기록 `docs/CHANGELOG.md`).

## 2. Google Play (안드로이드)
- ✅ 대상 안드로이드 버전 36(구글 요구: 새 앱은 API 36 이상). 안드로이드 16 에뮬레이터에서 실행 확인.
- ✅ **앱 번들(.aab)**: `sh tools/build_android.sh`가 `.apk`와 함께 서명된 `.aab`를 만든다(`dist/Sawasdee.aab`). 새 앱은 이 `.aab`를 플레이 콘솔에 올린다.
- 👤 Google Play 개발자 계정 등록(일회성 등록비). 계정 종류(개인/조직)에 따라 **출시 전 비공개 테스트 요건**(테스터 수·기간)이 있을 수 있으니 등록 시 안내를 확인.
- 👤 Play Console 입력: 앱 정보(`STORE_LISTING.md`), 개인정보 처리방침 주소, 데이터 보안 설문(수집·공유 없음), 콘텐츠 등급 설문, 광고 없음 표시, 대상 연령.
- 👤 Play 앱 서명 사용 여부 결정(권장: 켜기). 서명 키는 `docs/SIGNING.md` 참고.
- 👤 스크린샷: 휴대폰 최소 2장(가로·세로 비율 2:1 이내). `docs/store/screenshots/android/`.

## 3. App Store (아이폰)
- 👤 Apple Developer Program 가입(연회비). 팀 선택 후 Xcode에서 서명(Signing & Capabilities).
- 🔧 `ios/` 프로젝트: 번들 ID `com.sawasdee.thai`, 버전 0.4.0, iPhone 전용, 세로 고정, 암호화 면제 설정 ✅.
- ⚠️ **실기기 확인 필요**: 시뮬레이터에서만 시험했다. 그래픽(Metal)·소리·안전 영역을 실제 아이폰에서 본다. (winit 이 오래된 방식이라 `ios/Sawasdee/main.m`에 우회 코드가 있다. 라이브러리 업데이트 때 재확인.)
- 👤 TestFlight로 내부 테스트 → App Store Connect 입력(`STORE_LISTING.md`), 개인정보 처리방침 주소, 앱 개인정보("데이터 수집 안 함"), 연령 등급 설문.
- 👤 심사 메모: 로그인 없음. 단원 1~2 무료, 이후는 한 번 결제(인앱 상품 `full_unlock`). 시험용 라이선스 테스터 계정 안내를 적는다.
- ⚠️ 앱 종료 버튼은 iPhone에서 숨김 ✅(애플 심사 기준).

## 4. 출시 뒤
- 사용자 의견 창구(지원 이메일), 스토어 후기 확인, 오류 보고(통신을 넣을 때는 개인정보 처리방침과 데이터 설문부터 고칠 것).
- ✅ 유료화 구현(안드로이드): `docs/store/BILLING.md`. 👤 플레이 콘솔에서 인앱 상품 `full_unlock` 만들기, 내부 테스트로 결제·복원·환불 시험. 아이폰은 아직 없음.
