# 유료 전환(1~2단원 무료, 이후 한 번 결제)

## 동작
- **구글 플레이 빌드에서만** 켜져요(`sh tools/build_android.sh play`). 그냥 `sh tools/build_android.sh`로 만든 베타 APK는 결제가 없고 모든 단원이 열려 있어요(직접 설치한 앱에서는 구글 결제가 안 되기 때문).
- 단원 1~2(`FREE_UNITS` in `src/app.rs`)는 무료. 3단원부터는 학습 길에서 잠기고, 누르면 "전체 단원 열기" 창이 떠요.
- 상품: 인앱 상품 `full_unlock` (한 번 사면 계속 쓰는 상품, 구독 아님). 가격은 플레이 콘솔에서 정하고 앱은 그 가격을 그대로 보여 줘요.
- **구매 복원**: 서버·로그인 없이 구글 계정이 구매 기록을 가지고 있어요. 앱을 켤 때마다 `queryPurchasesAsync`로 확인하고(`Billing.java`), 결과를 폰에 저장해 인터넷이 없어도 열려 있어요. 환불되면 다음 확인 때 다시 잠겨요. 내 정보 → "전체 단원 · 구매 복원"과 결제 창에 "구매 복원" 버튼이 있어요.
- 결제가 끝나면 구매 확인(acknowledge)을 바로 해요. 3일 안에 안 하면 구글이 자동 환불해요.
- 학습 기록 백업 코드에는 구매 정보가 들어 있지 않아요(백업을 불러와도 공짜로 열리지 않음).

## 빌드
1. 처음 한 번: `android/libs/billing-9.1.0.aar`가 있어야 해요(구글 공식 저장소 dl.google.com, 약 530KB, git에는 올리지 않음). `python3 tools/fetch_billing_libs.py`가 의존 라이브러리까지 받지만 결제 라이브러리 하나만 있으면 돼서 나머지는 지워도 돼요.
2. `sh tools/build_android.sh play` → `target/release/apk/Sawasdee-play.aab`(플레이에 올릴 파일), `Sawasdee-play.apk`(시험용).

## 플레이 콘솔에서 할 일(사용자)
1. 결제 프로필(판매자 계정) 등록.
2. 앱 만들기 → **수익 창출 → 제품 → 인앱 상품**: 제품 ID `full_unlock`, 가격 설정, 활성화.
3. 내부 테스트 트랙에 `Sawasdee-play.aab` 업로드(결제는 플레이를 거쳐 설치한 앱에서만 동작).
4. **설정 → 라이선스 테스트**에 시험용 구글 계정을 넣으면 실제 돈 없이 결제·환불을 시험할 수 있어요.
5. 시험 순서: 설치 → 3단원 누름 → 결제 → 열림 확인 → 앱 삭제 후 재설치 → 자동으로 열림 확인 → 플레이에서 환불 → 앱 다시 켜면 잠김 확인.

## 아직 못 해 본 것
- 에뮬레이터에서는 결제창·구매 복원을 시험할 수 없어요(플레이 계정과 내부 테스트 트랙 필요). 잠금 화면과 결제 안내 창, 결제 라이브러리가 앱에 들어가 정상 시작하는 것까지만 확인했어요.
- 아이폰은 아직 결제가 없어요(애플 StoreKit과 "구매 복원" 버튼 필요).
