# 오픈소스 구성 요소와 라이선스

사왓디는 아래 오픈소스를 사용한다. 각 라이선스는 사용·배포를 허용하되 저작권 표시를 요구한다. 스토어 출시 때 앱 안에 '오픈소스 라이선스' 화면(또는 이 목록으로 연결되는 링크)을 두는 것이 안전하다.

## 글꼴 (앱에 포함)
- Noto Sans KR — SIL Open Font License 1.1 (`assets/fonts/OFL-NotoSansKR.txt`)
- Noto Sans Thai — SIL Open Font License 1.1 (`assets/fonts/OFL-NotoSansThai.txt`)
- egui 기본 글꼴 — egui 라이선스에 따름
