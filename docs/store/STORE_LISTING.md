# 스토어 등록 문구 (초안)

> 초안이다. 사실과 맞는 내용만 쓸 것: **원어민 검수를 마치기 전에는 "원어민 감수"라고 쓰지 않는다.** 다른 앱 이름·상표를 쓰지 않는다.

## 앱 이름 후보
- 사왓디 — 한국인을 위한 태국어 (Play 제목 30자 이내, 앱스토어 30자 이내)
- Sawasdee: 태국어 배우기

## 부제 / 짧은 설명
- App Store 부제(30자): `여행 태국어, 매일 10분`
- Google Play 짧은 설명(80자): `한글 발음과 성조 화살표로 배우는 태국어. 알파벳, 회화, 복습까지 한 앱에서.`

## 긴 설명 (Google Play 4,000자 / App Store 4,000자 이내)
```
태국 여행과 생활을 위한 태국어를, 한국어로 쉽게 배워요.

■ 한글 발음 + 성조 화살표
모든 단어와 문장에 한글 발음과 성조 화살표(→ ↓ ↘ ↑ ↗)를 붙였어요. 성조가 어려운 태국어를 눈으로 보고, 귀로 들으며 익혀요.

■ 레슨 32단원
기본 인사, 자기소개, 음식 주문, 길 찾기부터 카페, 호텔, 병원, 흥정, 관광, 데이트까지. 여행에서 바로 쓰는 말 위주로 단어 320개와 문장 200여 개를 담았어요.

■ 알파벳 학습 탭
자음 44자, 모음 23개, 받침, 성조 규칙, 이중 자음과 특수 표기, 태국 숫자까지. 글자표를 눌러 소리를 듣고, 퀴즈 10종으로 연습해요. 메뉴판과 표지판을 읽는 연습도 있어요.

■ 틀린 문제는 다시
틀린 문제는 오답 노트에 모였다가 다시 나와요. 잊을 때쯤 다시 보여 주는 복습으로 오래 기억해요.

■ 남성·여성 말투
태국어는 말하는 사람의 성별에 따라 문장 끝(ครับ/ค่ะ)과 '나'가 달라져요. 처음에 말투를 고르면 모든 문장이 맞게 바뀌어요.

■ 다양한 학습 방식
단어 카드, 듣기, 빈칸 채우기, 문장 만들기, 짝 맞추기, 따라 말하기까지. 퀴즈만 푸는 게 아니라 여러 방법으로 익혀요.

■ 개인정보를 수집하지 않아요
로그인이 없고, 학습 기록은 내 기기에만 저장돼요. 광고도 없어요.

※ 앱 속 태국어 음성은 AI 음성이에요. 원어민 검수는 진행 중이에요. [검수 완료 후 문구 변경]
```

## 키워드 (App Store, 100자 이내, 쉼표로 구분)
`태국어,태국,방콕,여행,회화,알파벳,성조,단어,발음,언어`

## 분류
- Google Play: 교육 · App Store: 교육 (보조: 여행)

## 연령 등급
- 폭력·성적 내용·도박·약물 없음, 사용자 생성 콘텐츠·인터넷 통신 없음 → 모든 연령. 설문 답변 때 "데이트" 단원은 연애 대화 예문(성적 내용 없음)이라고 답한다.

## 데이터 보안 / 개인정보 답변
| 질문 | 답 |
|---|---|
| Google Play 데이터 보안: 데이터를 수집·공유하는가 | **아니요** (수집·공유 없음) |
| 데이터는 전송 중 암호화되는가 | 해당 없음(전송 없음) |
| 사용자가 삭제를 요청할 수 있는가 | 앱 삭제 시 모두 삭제 |
| App Store 앱 개인정보: "수집하는 데이터" | **데이터를 수집하지 않음** (Data Not Collected) |
| 추적(ATT) | 사용 안 함 |
| 수출 규정(암호화) | `ITSAppUsesNonExemptEncryption = false` (설정됨) |
