# 지인 베타 안내 (안드로이드)

목적: 스토어에 올리기 전에 **10~20명**에게 써 보게 해서 ① 소리와 화면이 문제없이 도는지 ② 끝까지 쓰는지 ③ 내용 오류가 있는지 ④ 돈을 낼 만한지를 확인한다. 기간은 약 3주.

## 1. 앱 파일 전달
- 파일: GitHub 릴리스의 `Sawasdee.apk` (약 26MB, 안드로이드 8.0 이상): https://github.com/chrisguy7707-ui/sawasdee/releases/latest
- 카카오톡 등 메신저가 `.apk` 전송을 막으면 **구글 드라이브·파일 공유 링크**로 보낸다. 링크는 받는 사람만 열 수 있게 한다.
- 아이폰은 애플 개발자 계정(연회비)과 TestFlight가 있어야 시험 배포를 할 수 있다. 계정을 만들기 전에는 **안드로이드 사용자만** 모집한다.

## 2. 설치 방법 (참가자에게 보낼 글)
> 1. 보내 드린 `Sawasdee.apk` 파일을 폰에 내려받아 누르세요.
> 2. "출처를 알 수 없는 앱 설치" 허용 창이 뜨면 이 파일을 연 앱(크롬, 파일 앱 등)에 대해서만 허용하세요.
> 3. 설치가 끝나면 **사왓디**(금색 코끼리 아이콘)를 여세요. 처음에 말투(남성/여성)와 시작 단계를 고릅니다.
> 4. 시험이 끝나면 앱을 지우셔도 됩니다. 이 앱은 개인정보를 수집하지 않고, 학습 기록은 폰 안에만 저장됩니다.

## 3. 해 볼 일 (참가자에게 보낼 글, 약 20분)
1. 기초 단원 1의 레슨 2개를 끝까지 풀어 보세요. 소리가 나는지 확인하세요.
2. **알파벳** 탭에서 아무 퀴즈나 한 번 풀어 보세요.
3. 일부러 틀려 보고, **오답** 탭에 모이는지 보세요.
4. 앞으로 1주일 동안 하루 10분씩 편한 만큼 써 보세요.
5. 일주일 뒤 **내 정보 → 정보 → 학습 요약**을 열어 **화면을 캡처해서** 보내 주세요. 자동으로 전송되는 건 없어요.

## 4. 설문 (구글 폼 등에 그대로 옮겨 쓰기)
1. 폰 기종과 안드로이드 버전을 적어 주세요.
2. 소리가 잘 나왔나요? (예 / 일부만 / 안 나옴) 안 나온 곳이 있다면 어디인가요?
3. 앱이 멈추거나 꺼지거나 화면이 깨진 적이 있나요? 있다면 어떤 화면에서요?
4. 틀렸다고 생각한 태국어, 한글 발음, 성조, 뜻이 있나요? (단원과 단어/문장을 적어 주세요)
5. 가장 도움이 된 부분은 무엇인가요? 가장 불편하거나 지루한 부분은요?
6. 일주일 동안 며칠 사용했나요? 하루 평균 몇 분이었나요?
7. 이 앱이 유료라면 어떤 방식이 괜찮을까요? (무료 / 한 번 결제 ₩5,900 / ₩9,900 / ₩14,900 / 월 구독 / 안 쓴다)
8. 태국 여행이나 태국어 공부 계획이 있나요? (가까운 시기에 있음 / 언젠가 / 없음)
9. 이 앱을 친구에게 추천하시겠어요? (0~10점)
10. 하고 싶은 말이 있다면 자유롭게 적어 주세요.

## 5. 결과 읽는 법
| 지표 | 기준(제안) | 뜻 |
|---|---|---|
| 1주일 안에 레슨 5개 이상 | 참가자의 절반 이상 | 끝까지 쓸 만하다 |
| 심각한 오류 지적 | 단원당 몇 건 이하 | 내용을 믿을 수 있다 |
| 소리·화면 문제 | 같은 문제가 여러 기종에서 나오면 우선 수정 | 기술 안정성 |
| 문항 7에서 유료 응답 | 일부라도 있음 | 수익 가능성 신호 |
| 문항 9 추천 점수 | 평균 7 이상 | 입소문 가능성 |

기준을 못 넘으면 `docs/IMPROVEMENT_PLAN.md`의 보완 순서를 다시 정하거나, 방향 자체를 바꾼다(중단 포함).

## 6. 참가자 보호
- 이름·연락처는 설문에 꼭 필요한 만큼만 받는다. 캡처로 받은 학습 요약에는 개인정보가 없다.
- 오류를 알려 준 분께는 수정 반영 소식을 알려 준다(선택).
