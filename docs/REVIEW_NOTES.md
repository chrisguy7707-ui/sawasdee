# 원어민 검수 메모 (v0.3 새 단원)

새로 추가한 8개 단원(카페와 음료 · 맛과 취향 · 호텔과 숙소 · 데이트 · 흥정과 시장 · 관광과 사진 · 병원과 약국 · SNS와 휴대폰)은
**AI가 쓴 것이고 원어민 검수 전**이다. 아래는 작성자가 특히 확신이 낮은 곳이다. 이 항목부터 확인하면 된다.

## 어색할 수 있는 문장 (자연스러운 표현으로 바꿔야 할 수 있음)
| 단원 | 문장 | 걱정 |
|---|---|---|
| 병원과 약국 | ขอ หมอ ด้วย ครับ | "의사 불러 주세요"로는 어색할 수 있음 (보통 เรียกหมอ 등) |
| 병원과 약국 | นี่ ฉุกเฉิน | 구어로 자연스러운지 |
| 관광과 사진 | ขอ ไกด์ หนึ่ง คน | 가이드를 구할 때의 표현 |
| 관광과 사진 | ไป เกาะ ด้วย เรือ | "배로 섬에 가요"의 ด้วย 사용 |
| SNS와 휴대폰 | ตรงนี้ มี เน็ต ไหม | ที่นี่ 가 더 흔한지 |
| SNS와 휴대폰 | เบอร์ โทร อะไร ครับ | 전화번호를 묻는 말 |
| 카페와 음료 | ผม สั่ง กาแฟ | 평서문으로 자연스러운지 |
| 데이트 | ผม ชวน คุณ กิน ข้าว | 연인 사이 표현으로 자연스러운지, 높임말 수준 |
| 데이트 | ผม รัก คุณ / ผม คิดถึง คุณ | 실제 대화에서 쓰는 형태(ฉัน/ผม, เธอ 등) |

## 성조 코드·발음 표기 (직접 계산한 값, 확인 필요)
- 외래어 표기: เช็คอิน, เช็คเอาท์, ไวไฟ, แบตเตอรี่, ชาร์จ, โพสต์, ไกด์, แอป, ไลน์, ซิม, เน็ต, เมนู, กิโล
- 3음절 이상: ผ้าเช็ดตัว(FHM), พระราชวัง(HFM), ร้านขายยา(HRM), ต่อราคา(LMM), ทิวทัศน์(MH), แบตเตอรี่(LMF)
- 합성어를 한 단어로 취급한 것: น้ำแข็ง, น้ำตาล, น้ำร้อน, ห้องพัก, ท้องเสีย, เป็นหวัด, ด้วยกัน, ดอกไม้, ของขวัญ, ของแท้, ผลไม้, เสื้อผ้า, ผ้าไหม
- 한글 발음 표기는 기존 단원의 표기 규칙(된소리, 받침 ㅂ·ㅅ·ㄱ)을 따랐지만 장단음과 성조는 한글로 구분되지 않는다.

## 뜻 표기
- "แพ้" = 알레르기가 있다 / 지다(둘 다). 앱에서는 앞의 뜻만 보여 줌.
- "เจ็บ" = 아프다 (다치거나 찔려서). ปวด(쑤시고 아픈 통증)와 구분이 필요한지.

## 음성
- 모든 음성은 구글 Chirp 3 HD(AI 음성). 단어 하나만 읽을 때 성조·억양이 어색한 것이 있는지 들어 보기.

## 알파벳 탭 (v0.3.1)
- 자음 16자(ฃ ฅ ฆ ฌ ญ ฎ ฏ ฐ ฑ ฒ ณ ธ ภ ศ ษ ฬ)의 이름·대표 단어·한글 발음·뜻. 특히 ฏ(ปฏัก 몰이 막대), ฑ(มณโฑ 인물), ฌ(เฌอ 나무), ฒ(ผู้เฒ่า 노인).
- 모음 23개의 한글 소리 설명("어 (짧게, 입을 크게)", "으어 (길게)" 등)이 한국어 화자에게 맞는지, 예시 단어(จะ ถึง ชื่อ เล็ก แพะ โต๊ะ เกาะ พ่อ เจอ เสีย เรือ ตัว น้ำ).
- 성조 규칙표 15개 조건과 예시 단어, 예외 두 가지(ห นำ, อ นำ ย) 설명.
- 계급 분류: 중자음 9(ก จ ฎ ฏ ด ต บ ป อ), 고자음 11(ข ฃ ฉ ฐ ถ ผ ฝ ศ ษ ส ห), 저자음 24.

## 받침 8개·단어 읽기 (v0.3.0)
- 받침 묶음: ㄱ(ก ข ค ฆ) · ㄷ(จ ช ซ ฎ ฏ ฐ ฑ ฒ ด ต ถ ท ธ ศ ษ ส) · ㅂ(บ ป พ ฟ ภ) · ㅇ(ง) · ㄴ(น ญ ณ ร ล ฬ) · ㅁ(ม) · 이(ย) · 우(ว). 예시 단어: รัก เจ็ด รูป ห้อง กิน นม ไทย เร็ว.
- "단어 읽기 연습"은 한글 발음 표기를 정답으로 쓰므로, 발음 표기가 틀리면 퀴즈 정답도 틀린 것이 된다. 단어 발음 표기를 먼저 확인할 것.

## 읽기 연습·특수 표기·숫자 (v0.3.x)
- 표지판 14개(ทางเข้า ทางออก ห้ามเข้า ห้องน้ำชาย ห้องน้ำหญิง เปิด ปิด ลดราคา ระวัง อันตราย ฉุกเฉิน ที่จอดรถ ห้ามจอด ห้ามถ่ายรูป)의 태국어와 한글 발음, 뜻. 실제 현지 표지판에서 쓰는 표현인지, 영업 중/종료를 나타내는 เปิด/ปิด의 쓰임.
- 태국 숫자 ๐~๙의 모양과 읽는 말(ศูนย์ หนึ่ง … เก้า).
- 특수 표기 5묶음의 설명(이중 자음, ห 앞 글자, อ 앞 ย, 읽지 않는 글자 ์, 반복 부호 ๆ)과 예시. 특히 `เร็วๆ`를 AI 음성이 두 번 읽는지.
- 문장 읽기 퀴즈의 오답 선택지는 다른 문장의 한국어 뜻이라, 뜻이 비슷한 문장이 섞이면 정답이 둘로 보일 수 있다.

## 자동 검증 결과와 구어 성조 (v0.3.x)
- `tools/check_tones.py`로 378개 단어의 성조를 철자 규칙에서 다시 계산해 일치함을 확인했다(오류 2건 수정). **규칙 일치는 사전상 표준 성조가 맞다는 뜻이지 실제 구어와 같다는 뜻은 아니다.**
- 구어와 표준이 다를 수 있는 곳: `เมื่อไร`(표준 FM, 구어에서는 낮게 읽는 사람이 많음), `อร่อย`(규칙과 다른 예외, 사전 값 LL), `ก็`(항상 하강, 예외). 앱의 화살표는 표준을 따르고, AI 음성이 어느 쪽으로 읽는지는 들어서 확인이 필요하다.

## 전체 꼼꼼 검토 (2026-11-16, AI 검토 — 원어민 검수를 대신하지 않음)

앱의 태국어 1,109줄(단어 525, 문장 387, 보조 단어 62, 글자·모음·받침·성조·숫자·표지판·특수 표기)을 한 줄씩 다시 확인했다. 고친 것:

**성조 코드 오류 3건** (숨은 연결 음절을 빠뜨림. 분석기용 음절 분할도 같은 실수를 해서 자동 검사가 놓쳤다)
- `ผลไม้` RH → **RHH** (폰-라-마이), `น้ำผลไม้` HRH → **HRHH**, `พระราชวัง` HFM → **HFHM** (프라-랏-차-왕)

**철자 오류 1건**
- "방금 ~했다"는 `เพิ่ง`이 표준 철자다. `พึ่ง`은 "의지하다"라는 다른 말(구어에서 섞어 쓰지만 교재로는 틀림). 단어와 문장 `ผมเพิ่งมาถึงครับ`을 고쳤다.

**부자연스럽거나 뜻이 틀린 문장 10건** (새 음성 필요)
- `ผมมีวัคซีนแล้ว`(백신을 갖고 있다) → `ผมฉีดวัคซีนแล้ว`(백신을 맞았다)
- `ขอหมอด้วยครับ` → `ช่วยเรียกหมอหน่อยครับ`(의사 좀 불러 주세요)
- `นี่ฉุกเฉิน` → `ฉุกเฉินครับ`
- `ไปเกาะด้วยเรือ` → `นั่งเรือไปเกาะ`
- `ผมชวนคุณกินข้าว` → `ผมอยากชวนคุณไปกินข้าว`
- `บางทีผมจะไป` → `บางทีผมอาจจะไป`
- `ผมเปิดบัญชี` → `ผมอยากเปิดบัญชี`
- `ผมซักผ้าวันนี้ครับ` → `วันนี้ผมซักผ้าครับ`(어순)
- `ตอนเช้าผมตื่น`(아침에 일어나요: 내용이 어색) → `ตอนเช้าผมดื่มกาแฟ`
- `ผมไปเจดีย์` → `เจดีย์นี้สวยมาก`

**한글 발음 표기 통일 9건** (같은 소리를 다르게 적던 것)
- `เมื่อคืน` 므아큰→므어큰, `ต้องการ` 똥깐→떵깐, `ยกเลิก` 욕륵→욕르억, `ฝาก` 퐉→팍, `ของฝาก` 컹퐉→컹팍, `เจ็บ` 쩝→쩹, `เจ็บคอ` 쩝코→쩹커, `ชาร์จ` 착→찻, 글자 이름 `ฃอ ขวด` 쿠앗→쿠엇, `ฌอ เฌอ` 츠→츠어

**한국어 뜻 3건**: `ไม่หวานมากครับ` "너무 달지 않아요"→"너무 달지 않게 해 주세요", "이해 했어요?"→"이해했어요?", "언제 예요?"→"언제예요?"

남는 의문(원어민 확인 필요): 외래어 성조(`เดท`, `แอป`, `ชาร์จ`, `โพสต์`, `ลิฟต์`, `ฟรี` 등은 실제 발음이 철자 규칙과 다를 수 있음), `ไหม`의 실제 구어 성조(고성으로 많이 발음), `ลุงกับป้า`의 한국어 대응(큰아버지·큰어머니/이모), `ขอโต๊ะสองคนครับ`처럼 통하지만 교과서적이지 않은 표현.
